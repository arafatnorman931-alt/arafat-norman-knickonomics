# Arafat Analytics — Champonomics

**Champonomics: The Finances Behind Every NBA Champion**

A one-page financial dashboard for the 2026–27 New York Knicks, built with Next.js, Tailwind CSS, and Recharts.

## Features

- Searchable player cards for Jalen Brunson, Karl-Anthony Towns, OG Anunoby, Mikal Bridges, and Josh Hart
- Career Earnings, 2026–27 Salary, Future Guaranteed Earnings, and Projected Career Earnings, all calculated from season-by-season salary data
- Salary Outlook chart showing historical and projected earnings

## Disclaimer

All dollar amounts are placeholders. NBA financial data and projections are for educational purposes.
